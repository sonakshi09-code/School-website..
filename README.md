# 🎓 Annie Besant National School Website

A modern, responsive and premium school website created for **Annie Besant National School**, Patna, Bihar.

The website focuses on presenting the school's vision, leadership, academic classes, activities, memories and contact information in a clean and attractive interface.

---

## 🏫 About the School

**Annie Besant National School**

📍 Bengali Road, Mithapur, Patna – 800001, Bihar

🎓 Classes: **Nursery, LKG, UKG & Class 1–10**

The website is designed to provide students, parents and visitors with an engaging digital experience while showcasing the school's academic environment and activities.

## 🌐 GitHub Pages

This website can be hosted using **GitHub Pages** because it is a static HTML, CSS and JavaScript project.

After pushing the project to GitHub:

1. Open the repository.
2. Go to **Settings**.
3. Open **Pages**.
4. Select the required branch.
5. Select the root folder.
6. Save the settings.
7. GitHub will generate the live website URL.
